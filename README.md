# PSO 惯量权重对比实验

基于粒子群优化（PSO）的四种惯量权重策略对比实现，在 10 个标准测试函数上进行实验。

## 四种方法

| 标识 | 名称 |
|------|------|
| `LDW` | 线性递减惯量权重 |
| `RIW` | 随机惯量权重 |
| `CONCAVE` | 凹函数递减惯量权重 |
| `CONVEX` | 凸函数递减惯量权重 |

## 环境准备

**Python 3.8+**，安装依赖：

```bash
pip install numpy matplotlib
```

## 使用步骤

### 第一步：运行实验

```bash
python experiment.py
```

- 自动在 10 维和 30 维上各跑 100 次独立实验
- 多核并行加速，结果保存至 `results.pkl`
- 同时生成带时间戳的日志文件，如 `experiment_20260225_143000.log`
- 在对应的 `output/exN/` 下生成 `notice.md`，记录边界处理、RIW 版本、速度上限比例、随机权重区间等关键配置

### 第二步：生成图表和表格

```bash
python plot_results.py
```

- 在 `output/` 目录下输出：
  - `table_10D.png` — 10 维均值/标准差结果表
  - `table_30D.png` — 30 维均值/标准差结果表
  - `curves.png` — 典型函数收敛曲线图

## 项目结构

```
PSO1/
├── pso.py          # PSO 核心算法 + 4 种 ω 计算函数
├── benchmark.py    # 10 个标准测试函数（f1~f10）
├── experiment.py   # 实验主程序（并行运行 + 数据收集）
├── plot_results.py # 结果可视化（图表 + 表格）
├── output/         # 生成的图表输出目录
└── results.pkl     # 实验结果（运行后生成）
```

## 实验参数

| 参数 | 值 |
|------|----|

| 学习因子 c1, c2 | 2.0 |
| 独立运行次数 | 100 |
| 测试维度 | 10D, 30D |
